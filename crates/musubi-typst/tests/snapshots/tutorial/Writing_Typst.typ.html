Writing Typst

Notes are written in Typst: = for headings, - for lists, *bold*, _italic_, $x^2$ for math. Typst basics shows the rest: tables, code, images.

Musubi adds a few functions: tasks and flashcards.

  • Find the graph

Click a checkbox to switch its task between to do and done: the note is saved at once, no need to edit it.

Two last trials:

  1. Rename this note: edit it, change its first heading to = Typst is written, and save with :w. The file is renamed from the title, and every link to it follows: look at the backlinks.
  2. Trash and restore: create a note with Space n, move it to the trash with “Move the note to the trash” in the palette, then bring it back with “Show the trash”.
